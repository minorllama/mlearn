# MLearn

Machine learning for everything not PDEs.

(For PDEs: [mlpde](https://github.com/minorllama/mlpde))

* [snn_mnist](snn_mnist.py): A first example training a spiking neural network.

* [nengo-dl + tensorflow example](tf_nengo_ensembl_example.py): A first example training a nengo neuron ensembl.
  
* [synchronization in small world networks](nengo_small_world_sync.ipynb): Example looking at synchronization in small world leaky-integrate-and-fire neuron networks.
