# The refactored annotated transformer

The code here refactor the implementation of [transformer](http://nlp.seas.harvard.edu/annotated-transformer/): [the annotated transformer](http://nlp.seas.harvard.edu/annotated-transformer/), so it be read by tracing from `main` in [transformer_model.py](transformer_model.py) giving a top down view of architecture instead of jupyter notebook which gets into the details of the layers before getting to the code that wires the layers.
